# Preprint bundle: Twisted Kerr-mass vacuum fields (DRAFT, not published)

The files below form the planned Zenodo Publication/Preprint record. The software, data and logs are in the separate
software record, Ansatz Machine v1.2.0 (doi:10.5281/zenodo.24593416), and in the repository
https://github.com/sumit7194/ansatz-machine.

| file | what it is |
|---|---|
| `main.pdf` | the preprint (7 pages): result, setting, grades, method, verification, limits, reproducibility, AI assistance |
| `SUMMARY.pdf` | one page for non-specialists, including what we do not claim |
| `REFEREE_GUIDE.md` | for each claim: the file, the command, the expected output and the run time |
| `main.tex`, `SUMMARY.tex` | LaTeX sources (build: `tectonic -X compile main.tex`) |
| `fig_bounds_3_5.dat`, `fig_bounds_3_10.dat`, `make_figure_data.py` | Figure 1 data and the script that extracts it from the committed production logs |
